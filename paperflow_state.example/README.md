# 状态目录长什么样

这是 `paperflow_state/`（默认状态目录）的**模板**，里面的数字和论文全是占位的。

真正的状态目录由 `init` 生成，**不会进仓库**——因为里面是你的私人数据：
`config.json` 记着你的本地路径，`周报/`、`月报/` 会引用你自己笔记的内容。

```
paperflow_state/
├── config.json       init 生成。你一般不用手改，改也是改 per_week / citation_base
├── 本周.md            选填。一两句话写你现在卡在哪，会被读进下一周的判断
├── 进度.csv           账本。推过的论文记在这，后面几周不再重复推荐
├── 周报\2026-09-21_第1周.md
├── 周报\2026-09-21_第1周总结.md
└── 月报\2026-09.md
```

这里只放两个文件的示例，因为它们有固定格式；`周报/`、`月报/` 是 `week` 和
`summary` 直接渲染出来的 Markdown，跑一次就有了。
