# 状态目录长什么样

这是 `paperflow_state/`（默认状态目录）的**模板**，里面的数字和论文全是占位的。

真正的状态目录由 `init` 生成，**不会进仓库**——因为里面记着你的私人数据：
`config.json` 是本机路径，`进度.csv` 写着哪几篇已经推过。

```text
paperflow_state/
├── config.json       init 生成。你一般不用手改，改也是改 per_week / citation_base
└── 进度.csv           账本。推过的论文记在这，后面几周不再重复推荐
```

> `本周.md` 和 `周报月报/` 以前也在这里，现在搬进了 Obsidian 库——它们是你读的东西，
> 放在库里 Obsidian 才看得见，`阅读清单.md` 末尾那句「本周工程建议见 …」也才点得开。
> 所以状态目录现在只剩机器用的这两个文件。

这里只放两个文件的示例，因为它们有固定格式；`本周.md`、`周报月报/` 是 `week` 和
`summary` 直接渲染出来的 Markdown，跑一次就有了。
